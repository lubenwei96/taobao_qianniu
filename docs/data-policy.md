# 数据边界

GitHub 中的代码、通用模板、非敏感说明须适合公开阅读。仓库可见性可能变化，私人资料始终不提交。

真实供应商报价、采购信息、账本、订单、客户个人信息、原始经营截图和图片原稿放 `private/` 或仓库外私人存储；店铺密码、令牌放安全凭据管理工具。`.env` 被忽略，但忽略规则不保护已被追踪的文件。

第一次填写资料前，把模板复制到 `private/`。每次提交前运行 `git status` 与 `git diff --cached` 检查内容；不要用强制添加跳过忽略规则，不要把数据打印进公开日志。已提交敏感信息需要移除并及时轮换凭据；简单删除文件无法清除历史。

`private/` 不随 Git 同步。选择访问受控的私人云盘或其他存储，在电脑间同步这些数据，并检查访问权限。不得把 GitHub 同步成功描述为私人账本已同步。

商品文案须有事实依据，素材须具备使用权；未确认内容保留草稿，由用户决定发布。工具不登录淘宝、不读取客户信息、不自动下单或投放。
