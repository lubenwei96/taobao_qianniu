# 淘宝网络访问诊断

日期：2026-10-08，北京时间。目标是解决淘宝数据访问，暂不扩大品类调研。

## 实测证据

使用现有受管代理、保持系统 TLS 验证、不携带店铺账号、不跟随 HTTP 重定向检查：

| 地址 | 结果 |
| --- | --- |
| https://www.taobao.com/ | Tunnel connection failed: 403 Forbidden |
| https://s.taobao.com/ | 同上 |
| https://sycm.taobao.com/ | 同上 |
| https://login.taobao.com/ | 同上 |
| https://world.taobao.com/ | 同上 |
| https://www.tmall.com/ | HTTP 200 |
| https://www.bing.com/ | HTTP 200 |

读取 HTTPS CONNECT 响应的非敏感诊断头，淘宝搜索拒绝响应由 server: envoy 返回。响应头未提供可用于确认具体拒绝规则的原因，响应正文仅检出 forbidden；没有证据确认是未应用草稿、额外平台策略或其他代理规则。

## 已确认和未确认

- 已确认：受管代理拒绝到淘宝的 HTTPS 通道，请求尚未到达可用于分析的淘宝页面。此错误不是淘宝页面内的登录提示、验证码或反爬响应。
- 已确认：相同机器与代理可访问天猫首页，不能归因为所有外网均断开。
- 已确认：环境草稿 revision 3 包含 *.taobao.com、*.tmall.com、*.alicdn.com、*.alibaba.com 以及 s.taobao.com、sycm.taobao.com 等域名，保存成功。
- 未确认：上述草稿是否已发布、是否已应用到本运行实例。草稿内容不能证明运行时就绪，未找到读取实时代理策略或直接发布配置的工具。
- 未完成：淘宝商品检索、具体同行页面、生意参谋数据获取。

## 应用与复测

用户在环境设置中审阅并保存允许域名，发布环境配置；平台完成应用或恢复后，重新检查同一批地址。不改变代理路线、不禁用 TLS、不更换域名镜像、不绕过平台限制。

验收按层次完成：

1. 代理允许 HTTPS CONNECT，不再返回通道 403。
2. 能读到淘宝真实首页或平台登录页面，确认重定向域名在允许范围内。
3. 使用有权限的合法登录途径，验证商品搜索或所需经营数据。账号权限和付费数据权限单独验收，不在聊天中索要密码。
4. 至少读取可核实的店铺名称、链接、商品规格与价位，才开始给出同行调研结论；生意参谋指标需相应账号权限。

如果已发布且仍有同样拒绝，需要平台支持检查此实例的代理 egress 规则、通配符匹配和配置应用状态。支持请求可附本记录，不附代理凭据、店铺密码或客户资料。

浏览器代理 CA 的安全设置变更此前被自动审批拒绝，尚未执行；该项不是当前 CONNECT 403 的解决方案，不在此步骤重复请求证书修改批准。
