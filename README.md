# 淘项 · 淘宝店铺运营协作工作区

用于我们持续合作选品、准备商品和复盘利润。代码和可公开模板通过 GitHub 同步；实际私人数据另行保存。

经营目标：北京时间 **2026 年 11 月 11 日，单日经营净利润超过 2000 元**。启动预算 5000 元以上，具体上限和品类尚未确定。软件交付不代表经营目标达成。

## 从这里开始

1. 阅读 [店铺档案](operations/store-profile.md) 和 [阶段路线图](operations/roadmap.md)。
2. 将 `templates/` 复制到 `private/` 后填写真实信息，保留数据来源和采集日期。不要直接在可公开模板填写报价或账本。
3. 用利润工具验证候选成本模型，结合货源、竞争、售后和履约能力决定是否测试。
4. 助手负责分析和商品草稿；用户核实事实并决定采购、投放、发布。记录结果，再根据真实经营数据调整。

## 运行与验证

Python 3.11+，不需要安装第三方包。云端在 `/workspace/taobao_qianniu` 操作；现有任务已经隔离，不创建 Git worktree。没有常驻服务需要启动。

```bash
cd /workspace/taobao_qianniu
python3 --version
python3 -m unittest discover -s tests -v
python3 -m taoxiang --help
```

假设案例：售价 100、采购 30、包装 2、运费 5、平台费率 5%、每单推广 8、每单预计售后 3、日其他费用 100，成交 50 单。

```bash
python3 -m taoxiang --price 100 --purchase 30 --packaging 2 --shipping 5 --fee-rate 0.05 --advertising 8 --aftersales 3 --fixed 100 --orders 50
```

预计贡献利润 47.00 元/单，预计日利润 2250.00 元，日利润严格超过默认目标 2000 元至少需要 45 单。例子为假设，不能作为市场数据或采购依据。通过 `--target` 可调整测算目标。

所有费用都必须显式填写，确实为零时填写 0。金额最多 12 位整数和 6 位小数，单量为最多 12 位的非负整数；费率为 0–1。命令错误退出码非零。亏损或零贡献利润明确提示无法通过增加单量达到目标。

## 利润口径

预计每单贡献利润 = 实收售价 × (1 − 平台费率) − 采购 − 包装 − 商家运费 − 推广 − 预计售后损失。

预计日经营净利润 = 每单贡献利润 × 日单量 − 日固定及其他经营费用。

税费、人工等必须根据实际情况计入成本项或日其他费用，未录入的费用没有被扣除。推广不要同时计入每单成本和日其他费用。尚未结清售后时结果为预计，最终利润需要实际账目核验。目标单量使用未舍入利润计算，展示金额四舍五入到两位小数。
